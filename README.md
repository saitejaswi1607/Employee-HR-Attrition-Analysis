# Employee HR & Attrition Analysis

This project uses employee data to explore why employees leave a company and whether factors such as overtime, job satisfaction, salary, experience, and job role are related to attrition. I used MySQL to organize the data and SQL queries to explore different employee and attrition patterns.

## Tools Used

- MySQL
- SQL

## What I Worked On

- Created a database and employee table in MySQL.
- Imported the HR employee dataset into MySQL.
- Explored employee counts across departments and job roles.
- Calculated overall and department-level attrition rates.
- Compared attrition based on overtime, job satisfaction, work-life balance, and years at the company.
- Analyzed average income by department and job role.
- Used `CASE WHEN`, aggregations, JOINs, and subqueries for different parts of the analysis.

## Questions I Explored

- Which departments have higher employee attrition?
- Which job roles have higher attrition rates?
- Does overtime appear to be associated with higher attrition?
- How does attrition vary with years at the company?
- How does job satisfaction relate to attrition?
- Which job roles have higher average monthly income?
- Which employees earn above the overall average income?

## Project Files

- `Employee_HR_Attrition_Analysis.sql` — SQL queries used for the analysis
- `dataset.csv` — Employee dataset used for the project

## About the Project

The goal of this project was to practice SQL on a realistic employee dataset while using the queries to answer practical HR-related questions rather than just running basic database queries.
